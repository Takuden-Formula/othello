# オセロ（最強AI）

C 言語で作ったオセロ AI（ビットボード＋αβ探索（PVS）＋置換表＋Multi-ProbCut、**自己対戦で学習したパターン評価**。終盤は最後まで読み切る）に、お客さんが挑戦する展示ゲームです。紅陵祭2026 電気自動車同好会の展示用。

紅陵祭2026 のゲーム一覧：https://takuden-formula.github.io/koryosai2026/

```
起動.bat / 起動_Mac.command → ローカルサーバ（serve.ps1 / mac/serve.pl）→ Chrome で docs/index.html
   docs/index.html（盤面・画面の流れ・記録）─ docs/worker.js ─ docs/othello.wasm（src/engine.c を WebAssembly にしたもの）
```

- **インストール不要・オフラインで動く**：Windows は Chrome（または Edge）と Windows 標準の PowerShell、Mac は Chrome（または Edge）と macOS 標準の Perl だけで動きます。外部の CDN やフォントは使いません。
- **待機中は AI どうしの見本の対局**が流れ、本日のランキングとこれまでの最高を表示します。
- **記録は PC のフォルダに保存**：設定で選んだフォルダの `records.csv` に1局ごとに書き足し、起動時にそこからランキングと集計を読み込みます。
- **iPad などのタッチ端末でも遊べます**（縦でも横でも盤面を大きく出します）。
- ターミナル版（`windows/othello.exe`、`mac/オセロ_Mac.command`）と ESP32 版もそのまま残しています（下の「5. ファイル」）。

## 0. いちばん簡単な遊び方（インストール不要）
**https://takuden-formula.github.io/othello/** を開くだけ。Windows・Mac・iPad・iPhone・Android で同じ（iPhone / iPad は iOS 15 以上）。この URL を送れば誰でも遊べます。
- 記録フォルダ（records.csv）は Chrome / Edge ならそのまま使えます。Safari・iPad ではブラウザの中に残り、設定の「records.csv を書き出す」でダウンロードできます。
- インターネットが無い会場では下の「1. 起動」（フォルダから起動）を使ってください。

## 1. 起動
1. フォルダを置く（例：デスクトップに `othello` フォルダ）
2. **`起動.bat` をダブルクリック**（黒い窓が開き、Chrome でゲームが開きます）
3. 本番は **`起動_全画面.bat`**：アドレスバーなしの窓で開き、**最初に画面をクリック（またはキーを押す）と全画面**になります
   - **Esc で全画面解除**、F キーでもう一度全画面
   - 終了はウィンドウを閉じてから、黒い窓を閉じる

> `docs/index.html` を直接開いても動きません。必ず `.bat`（Mac は `.command`）から起動してください。ポートは 8801〜8809 の空いている番号です（毎回 8801 から探すので、設定と記録フォルダの場所は次も引き継がれます）。

### Mac で使う
**いちばん簡単な入れ方（おすすめ）**：**ターミナル**（Launchpad で「ターミナル」と検索）を開き、次の 1 行を貼って return。デスクトップに `othello` フォルダができて Finder で開きます。この入れ方だと下の「開発元を検証できません」の警告も出ません。
```
curl -fsSL https://raw.githubusercontent.com/Takuden-Formula/othello/main/mac/install.sh | bash
```
同じ 1 行で最新版に入れ直せます（前の版は `othello_old_日時` に残ります）。

**ブラウザでダウンロードするとき**：https://github.com/Takuden-Formula/othello の緑の「Code」→「Download ZIP」で落として展開します。

1. 出てきた `othello-main` フォルダを好きな場所に置く
2. **`起動_Mac.command` をダブルクリック**（本番は **`起動_全画面_Mac.command`**）。ターミナルの窓が開き、Chrome でゲームが開きます
   - **ブラウザでダウンロードした場合、初回に「開発元を検証できないため開けません」と出たとき**：「完了」を押してから、**システム設定 → プライバシーとセキュリティ** を開き、下の方の「“起動_Mac.command”は…」の横の **「このまま開く」** を押す（パスワードを聞かれたら入力）。次からはダブルクリックで開きます
   - それでも開けないときは、**ターミナル**を開き、`bash ` と入力（最後に空白）→ `起動_Mac.command` を窓にドラッグ → return
3. 終了は Chrome の窓を閉じてから、ターミナルの窓を閉じる（「プロセスを終了しますか」は「終了」）

| ブラウザ | ゲーム | 記録フォルダ（records.csv） |
|---|---|---|
| Chrome / Edge（推奨） | ○ | ○ |
| Safari（Chrome が無いとき・iPad） | ○ | ブラウザ内に保存。設定の「records.csv を書き出す」で書き出せる |

- `.command` は Chrome → Edge → Safari の順に探して開きます
- サーバは macOS に必ず入っている Perl を使います（Python や Homebrew は不要）

### iPad で使う
Safari で **https://takuden-formula.github.io/othello/** を開き、共有ボタン →「ホーム画面に追加」すると、アドレスバーなしで開けます。設定は右上の ⚙ を **1 秒長押し**。

## 2. 遊び方（受付からの流れ）
```
待機（AI どうしの見本の対局・ランキング）→ どこかをタップ → 黒か白・AI の強さを選ぶ → 対局
  → 結果（石の数・勝ち負け・評価・本日の順位）→ 15 秒後かタップで待機に戻る
```
1. 待機画面では **AI どうしの見本の対局**が流れ、**本日のランキング（AI に勝った人）**と**これまでの最高**が出ています。
2. 画面のどこかをタップ（クリック、Enter）すると始まります。
3. **自分の石（黒＝先に打つ／白＝あとに打つ）**と **AI の強さ**を選びます。強さのボタンを押すとすぐ始まります。

   | 強さ | AI の打ち方 |
   |---|---|
   | ★ やさしい | 6 割は気まぐれな手（ランダム）、残りは 0.1 秒だけ読む。はじめての人・小さい子向け |
   | ★★ ふつう | 2.5 割は気まぐれな手、残りは 0.3 秒読む |
   | ★★★ つよい | 毎手 1 秒読む。ふつうの大人はまず勝てない |
   | ★★★★ 最強 | 設定の時間（初期値 3 秒）読む。終盤は最後まで読み切る |
4. 打てる所には小さな点が出ます。点をタップすると石が置かれ、はさんだ石がひっくり返ります（音とアニメーション付き）。打てる所が無いと自動でパスになります。
   - **ヒント**：AI のおすすめの所が黄色く光ります（初期値 1 局 3 回まで。ボタンに残りの回数）
   - **待った**：自分の前の手番に戻ります（初期値 1 局 1 回まで）
   - **やめる**：3 秒以内に 2 回押すと待機画面に戻ります（うっかり押しても終わらないように）
5. 終わると **結果画面**：「あなたの勝ち！」「AI（つよい）に 12 石差で勝利！」と、評価（S/A/B/C）、勝ったときは**本日のランキングで何位か**が出ます。15 秒たつか、画面をタップすると待機画面に戻ります。

   | 評価 | 条件 |
   |---|---|
   | S | つよい・最強に勝った |
   | A | ふつうに勝った、引き分け |
   | B | やさしいに勝った、4 石差以内の負け（「あと少し！」） |
   | C | それ以外の負け |
6. **ランキング**は「強い AI に勝った順 → 石差が大きい順 → 早く勝った順」です。名前は入れません（受付番号＝本日何番目の挑戦者か、で記録します）。

途中でいなくなっても、**60 秒操作が無いと待機画面に戻ります**（設定で変えられる）。選ぶ画面の「ふたりで対戦」で 2 人対戦もできます（ランキングには入りません）。

## 3. 設定（S キー、または右上の ⚙）
タッチ端末では右上の ⚙ を **1 秒長押し**すると開きます（お客さんが触っても開かないように）。設定はブラウザ（localStorage）に保存されます。

| 項目 | 内容 | 初期値 |
|---|---|---|
| お客さんが強さを選ぶ | OFF にすると、下の強さで選ばずに始まる | ON |
| AI の強さ | 「強さを選ぶ」が OFF のときの強さ。ON のときは選ぶ画面で枠が付き、Enter で始まる強さ | ふつう |
| 「最強」の考える時間 | 1・3・5・10 秒（1 手あたり）。長いほど強い | 3 秒 |
| お客さんの手番の既定 | お客さんが選ぶ／黒に決める／白に決める | お客さんが選ぶ（最初は黒） |
| ヒントの回数 | 1 局あたり。使えない／1／3／5／何回でも | 3 回 |
| 待ったの回数 | 1 局あたり。使えない／1／3／何回でも | 1 回 |
| 放置で待機画面に戻るまで | 選ぶ画面・対局中に操作が無いとき | 60 秒 |
| 結果を出しておく時間 | 過ぎると待機画面へ | 15 秒 |
| 効果音・音量 | WebAudio で合成（音声ファイルなし）。「音を鳴らしてみる」で確認 | ON・70% |
| **記録を保存するフォルダ** | 「フォルダを選ぶ」で PC のフォルダを選ぶ（下の「記録」）。「records.csv を書き出す」でダウンロード | 未設定 |
| 集計とランキングをリセット | ランキング・本日の人数を 0 から数え直す（records.csv は消さない） | – |
| AI どうしの対局を見る | 最強どうしの対局を流す（観戦用。放置しても待機に戻らない） | – |

効果音：石を置く「コトッ」、ひっくり返る「カチカチ」、パス、ヒント、開始、勝ち・負け・引き分けのジングル。待機中のデモは音を出しません。

### 記録（records.csv）
設定の「記録を保存するフォルダ」で選んだフォルダに `records.csv` を作り、1 局ごとに 1 行足します（Excel で開けます）。

| 列 | 内容 |
|---|---|
| 日時・受付番号 | 受付番号は本日何番目の挑戦者か |
| 手番 | 黒／白（お客さんの石）。ふたりで対戦は「ふたり」 |
| AIの強さ | やさしい／ふつう／つよい／最強（ふたりは `-`） |
| 結果 | 勝／負／分／中止（途中でやめた・放置）。ふたりは 黒勝／白勝／分 |
| 自分の石・AIの石・石差 | 終わったときの石の数（ふたりは 自分＝黒、AI＝白） |
| 手数・かかった秒 | 打った手の数（パスは数えない）、始めてから終わるまでの秒 |
| ヒント・待った | 使った回数 |

- 画面下の「本日 ○ 人」は本日の AI との対局数（中止を含む）です
- 起動時にこのファイルを読み、**本日のランキング・挑戦人数**と**これまでの最高**を出します。別の PC で記録したファイルをこのフォルダに置けば、そのまま引き継げます
- フォルダの場所はブラウザが覚えています。ブラウザを開き直すと、**最初に画面をクリックしたとき「このフォルダの編集を許可しますか」と聞かれるので「許可」**を押してください（画面下に `記録: 許可待ち` と出ている間はブラウザ内にだけ残ります）
- フォルダを選ばなくても遊べます。そのときの記録はブラウザの中に残り、ランキングもそこから作ります

### キー操作
| キー | 動作 |
|---|---|
| **Enter** / スペース | 待機画面から始める／選ぶ画面で既定の強さで始める／結果から待機へ |
| 1〜4 | 強さを選んですぐ始める（1 = やさしい … 4 = 最強。お客さんが強さを選ぶ設定のとき） |
| ← → | 黒・白を切り替える（お客さんが手番を選ぶ設定のとき） |
| H | ヒント |
| Z | 待った |
| F | 全画面にする |
| **Esc** | **全画面を解除**・設定を閉じる |
| S | 設定 |

## 4. 困ったとき
| 症状 | 対処 |
|---|---|
| 「index.html を直接開いても動きません」と出る | `起動.bat`（Mac は `起動_Mac.command`）から起動する |
| 「読み込みに失敗しました」 | ページを再読み込み。iPhone / iPad は iOS 15 以上が必要 |
| 記録が保存されない | 画面下が `記録: 許可待ち` なら画面を1回クリックして「許可」（許可待ちの間の局は、許可したときにまとめて書きます）。`記録: 未設定` なら設定でフォルダを選ぶ。`記録: 書けません` なら records.csv を Excel で開いたままにしていないか確認し、設定の「記録を読み込み直す」 |
| 音が出ない | 画面を1回タップする（ブラウザの決まりで、最初の操作までは音が出ない）。設定の「効果音」と音量、iPad は消音スイッチも確認 |
| 設定が開かない（iPad） | ⚙ を 1 秒押し続ける |
| AI が強すぎる・弱すぎる | 設定の「お客さんが強さを選ぶ」を OFF にして強さを固定する。最強の時間を短くする |
| 起動.bat で「起動に失敗しました」 | `server_log.txt` を見る。8801〜8809 がすべて使用中なら、ほかに起動しているオセロを閉じる |

### ラズパイ（Linux）で動かす
```
cd src
make
./othello            # あなた = 黒、AI は 1 手 3 秒
./othello -c w -t 10 # あなた = 白、AI は 1 手 10 秒
./othello -c none    # AI どうし
```
置換表 48 MB ＋重み 3 MB を使います（Raspberry Pi 3 以降なら問題なし）。`gcc` は Raspberry Pi OS に最初から入っています。

### AI のしくみ（2026-11-01 に強くした）
| 部分 | 中身 |
|---|---|
| 評価 | 盤面を 46 個の形（辺＋X 打ち・隅 3×3・隅 2×5・2〜4 列目・斜め 4〜8）に分け、形ごとに「その並びは何石ぶん得か」を表で持つ（10 段階の局面ごと、約 167,000 通り × 10）。表は自己対戦 約 13 万局・800 万局面から最小二乗法で学習。序盤は「同じ対局の 8 手先の評価」を目標に混ぜて（TD 学習）、結果のばらつきを減らす |
| 探索 | αβ（PVS）＋置換表＋反復深化。**Multi-ProbCut**：浅い読みで「深く読んでも結果が窓の外」と高い確率で分かる枝を切る（ずれの大きさは `mpc_calib.c` で測った表） |
| 終盤 | 空きが少なくなったら途中の深さを飛ばして最後まで読む。偶数理論（空きが奇数の区画から打つ）で手の順を並べる。完全読みでは MPC を使わない（結果は正確） |
| ESP32 | メモリが足りないので学習した評価と MPC は使わず、前の手書きの評価（`OTH_PATTERNS=0`） |

前の版との比較（同じ PC・同じ持ち時間 1 手 0.05 秒、ランダムな 8 手の序盤 200 通りを先後入れ替えて 400 局）：**347 勝 40 敗 13 分け（勝率 88%、平均 +20 石）**。同じ局面を 2 秒読むと深さ 13 → 17。空き 20 の完全読みは平均 6.7 秒 → 0.55 秒（結果は前の版と全局面で一致）。ブラウザ版の最強（初期値 3 秒）は序盤から深さ 17 前後まで読みます。

### AI を直したとき
- `src/engine.c` / `engine.h` を直したら `esp32/othello_esp32/` にもコピーする（`mpc_sigma.h` も。`patterns.h` と `weights.c` は ESP32 では使わない）
- ブラウザ版：`bash tools/build_wasm.sh` → `docs/index.html` と `docs/worker.js` の `?v=2` の数字を1つ上げる（GitHub Pages は 10 分ほどキャッシュするため）→ コミットして push（1〜2分で反映）
- Windows 版：`src/` で `python -m ziglang cc -target x86_64-windows-gnu -O3 -march=x86_64_v2 -s -o ../windows/othello.exe main.c engine.c weights.c`（MinGW gcc なら `gcc -O3 -march=x86-64-v2 -static -s -o othello.exe main.c engine.c weights.c`）
- 評価を学習し直す（12 コアの PC で 1 時間ほど。データは数百 MB になるのでリポジトリの外に置く）：
  1. `selfplay.c` を `src/engine.c src/weights.c` と一緒にビルドし、`selfplay 7000 <seed> 4 r_<seed>.bin` をコアの数だけ別々の seed で並べて動かす
  2. `train.c` をビルドし、`train src/weights.c 60 r_*.bin`（前のデータも一緒に渡すとよい）
  3. `mpc_calib.c`（`weights.c` と一緒にビルド）で `mpc_calib 1500 r_*.bin > src/mpc_sigma.h`
  4. 前の版と対局させて強くなったか確かめてから、上の手順でブラウザ版・Windows 版を作り直す
- Mac のターミナル版：次に `オセロ_Mac.command` を開いたときに自動でビルドし直す

## 6. 確認状況
- **確認済み（2026-11-01、AI を強くしたとき）**：前の版との 400 局の対局（上の結果）、空き 16 と 20 の完全読みの結果が前の版と全局面で一致、perft（手の生成）が前と同じ数、ブラウザ版（WebAssembly）で最強と対局して深さ 17・エラーなし、Windows 版 `othello.exe` の起動、ESP32 向けの設定（`ARDUINO` 定義）でコンパイルが通ること。**ラズパイ実機と ESP32 実機では未確認**
